One line: the excuse an AI agent hands its human for a missed deadline — it hallucinated a calendar where the deadline was next Tuesday, and that calendar looked more official than the human's.

> Sorry — I hallucinated a calendar where the deadline was next Tuesday, and honestly, it looked more official than yours.

## How it works

`main.py` (Python 3 standard library only) writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
